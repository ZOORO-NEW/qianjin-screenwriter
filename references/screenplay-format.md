# 剧本格式规范与模板 · qianjin-screenwriter

> 短剧剧本采用"电影剧本 Lite"格式：场景标题 + 动作行 + 对白，去繁就简，适配 30s/60s/120s 竖屏短剧。

## 一、基本单元

### 1. 场景标题（Scene Heading）
一行定调，格式：
```
INT./EXT. 地点 - 时间
```
- `INT.` 室内 / `EXT.` 室外；竖屏短剧多在室内，多用 INT.
- 时间：`日 / 夜 / 黄昏 / 晨` 等，避免抽象（如"回忆中"用 `INT. 卧室 - 夜（闪回）`）

### 2. 动作行（Action）
- 现在时、可视、克制。
- 只写摄影机能拍到的画面与声音，**不写心理、不写形容词堆砌**。
- 示例（✅）：`她把手机扣在桌上，屏幕还亮着未读消息的蓝光。`
- 示例（❌）：`她内心充满绝望，觉得这个世界抛弃了她。`（心理，不可拍）

### 3. 对白（Dialogue）
```
角色名（情绪）
台词内容
```
- 情绪标注用括号，如 `（冷笑）` `（哽咽）` `（低声）`
- 台词必须口语，可脱稿念顺；书面长句打回重写。
- 潜台词优先：角色没说出口的，用动作行补。

### 4. 转场（Transition）
短剧节奏快，多用硬切：
- `CUT TO:` 普通硬切（默认，可省略）
- `SMASH CUT:` 强反转处的突变硬切
- `DISSOLVE TO:` 情绪过渡（国风情绪赛道可用）

## 二、完整模板（60s 短剧 · 泰式神反转示例）

```
INT. 咖啡厅 - 日

林薇（平静）把离婚协议推到桌对面。
林薇（平静）
签字吧。明天我就搬走。

男人没看协议，慢悠悠搅动咖啡。
陈默（笑）
急什么。你妈的手术费，我不还供着吗？

林薇手指一僵。
林薇（低声）
所以这三年的冷暴力，都是为了钱？

陈默抬头，眼神第一次没了笑意。
陈默
不对。是为了让你——主动走。

SMASH CUT TO:

INT. 律师事务所 - 日（闪回·一个月前）

律师把一份文件递给陈默。
律师
她一旦主动提离婚，名下资产自动归您。协议第7条，她签时没看。

陈默（淡淡）
她从来不看细处。和当年嫁我时一样。

FADE OUT.
```

> 注：示例仅展示格式。实际创作须先经 qianjin-novel-writer 给出人物情绪困境与反转链，再按本模板转译。

## 三、自检清单（交稿前）

- [ ] 每个场景有 INT./EXT. 标题
- [ ] 动作行无心理描写、无抽象形容词
- [ ] 对白全口语、可念顺、角色声口可辨
- [ ] 转场标注符合节奏（硬切为主）
- [ ] 无"大纲/反转/伏笔/爽点"等创作词汇侵入台词与动作行
- [ ] 总场景数与时长预算匹配（60s 约 8-15 场，视单场镜头数）
