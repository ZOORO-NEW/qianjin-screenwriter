# 分镜表规范与节奏公式 · qianjin-screenwriter

> 把剧本逐场拆成"镜头级"指令，直接喂给生图/图生视频/配音/合成。列定义、模板、时长分配公式三合一。

## 一、分镜表列定义

| 列 | 含义 | 写法要点 |
|----|------|---------|
| 镜头号 | SHOT_001 递增 | 连续无跳号，便于素材对齐 |
| 景别 | 远景/全景/中景/近景/特写(CU)/过肩(OTS) | 情绪点用 CU，对话用 OTS 正反打 |
| 画面描述 | 可见可执行的具体画面 | 禁用"氛围感/高级感"，用光/色/构图写 |
| 台词 | 该镜头念出的对白 | 与剧本对白一致，空镜留空 |
| 时长 | 秒数 | 单镜 2-5s |
| 运镜 | 固定/推/拉/摇/移/手持/升降 | 反转点用手持或急推 |
| 音效 | BGM/环境音/音效/静默 | 情绪留白标"静默" |

## 三、节奏公式（番茄爆款）

### 时长分配（60s 为例）
- 开场钩子：前 3s 必出冲突/反转/奇观（占 1 个镜头）
- 中段升级：约 40s，每 3-5s 一信息点，反转点安排在 15s / 30s / 45s 附近
- 结尾爆点：最后 5-8s 神反转或情绪高点，留 1 个空镜/反应特写

### 信息点密度
- 单镜头 ≤ 1 个核心信息（谁/在哪/做什么/情绪）
- 对话戏：正反打交替，单镜不超 5s
- 动作/奇观戏：可拉到 2-3s 特写慢放制造张力

### 景别节奏
- 快切段：中景→近景→CU 快速切换（爽感）
- 情绪段：CU 停留 + 慢推（共情）
- 转场：硬切为主，情绪过渡用 dissolve

## 四、自检清单（交稿前）

- [ ] 镜头号连续无跳号
- [ ] 每列无空缺（空镜台词/音效标"无/静默"）
- [ ] 单镜时长 2-5s，累计 = 目标总时长（±2s）
- [ ] 画面描述具体可执行，无抽象词
- [ ] 运镜明确，反转点有对应镜头语言
- [ ] 台词与剧本一致，可念
- [ ] 情绪爆点有 CU / 空镜留白
