# qianjin-screenwriter · 短剧剧本编剧

qianjin 系列的「视听转化层」：把 qianjin-novel-writer 产出的故事内核，翻译成可直接拍摄的**短剧剧本**与**分镜脚本**。

## 能力
- 故事梗概 / 小说大纲 → 短剧剧本（场景标题 / 动作行 / 角色对白）
- 剧本 → 分镜脚本（镜头号 / 景别 / 画面 / 台词 / 时长 / 运镜 / 音效）
- 短剧爆款节奏（泰式神反转 / 国风情绪 / 都市爽文）
- 对白口语化改写、角色声口一致性
- 可拍性三审（格式合规 / 镜头可执行 / 对白可念）

## 与 qianjin-novel-writer 的关系
| | novel-writer | screenwriter |
|--|--|--|
| 产出 | 小说叙事体 / 大纲 / 角色卡 | 剧本 / 分镜 |
| 调用顺序 | 先（故事内核） | 后（视听转化） |

## 使用
对话中说「把这段梗概写成 60s 短剧剧本和分镜」，或承接 short-drama-autopilot 编排器的分镜拆解阶段。
